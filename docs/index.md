# Курс Jira для новачків

Ласкаво просимо. Це практичний курс, який проведе тебе від першого знайомства з Jira до впевненого налаштування системи для команди.

## Для кого цей курс

Для тих, хто:

- Ніколи не відкривав Jira, але хоче розібратись.
- Вже користується Jira, але без системи, як зручний список задач.
- Хоче рости до PM і навчитись вибудовувати роботу команди, а не лише заповнювати беклог.

## Що ти вмітимеш після курсу

- **Налаштовувати Jira** — проєкти, дошки, workflow.
- **Організовувати роботу** — backlog, задачі, спринти.
- **Працювати з JQL** — пошук, фільтри, складні запити.
- **Створювати dashboards** — звіти й прозорість для команди.
- **Автоматизовувати рутину** — Jira Automation.
- **Використовувати Jira як PM** — реальні сценарії та best practices.

## Як проходити курс

Курс складається з шести модулів. Кожен модуль — це теорія + практика. Не пропускай практику. Бо Jira — це навичка, а не знання. Її не можна вивчити, читаючи.

**Порада:** створи окремий тестовий проєкт у Jira і роби всі вправи там.
Не бійся ламати — це пісочниця.

## Зміст курсу

| Модуль | Тема                                 |
| ------ | ------------------------------------ |
| 1      | Фундамент — простори, проєкти, дошки |
| 2      | Backlog, задачі та спринти           |
| 3      | JQL — мова запитів                   |
| 4      | Dashboards та звіти                  |
| 5      | Automation — рутина під контролем    |
| 6      | Jira як PM — реальні сценарії        |

## З чого почати

Якщо ти зовсім новачок — почни з **Модуля 1**. Не пропускай його, навіть якщо здається очевидним. Там закладається фундамент, без якого решта не матиме сенсу.

Готовий? Обирай модуль і вперед.
