# Курс Jira для новачків

Практичний курс з Jira: від першого знайомства до впевненого налаштування системи для команди.

**Відкрити курс:** https://betabutterfly.github.io/jira-course/

## Про курс

Це навчальний матеріал для тих, хто:

- Ніколи не відкривав Jira, але хоче розібратись.
- Вже користується Jira, але без системи, як зручний список задач.
- Хоче рости до PM і навчитись вибудовувати роботу команди, а не лише заповнювати беклог.

Курс безкоштовний. Читати можна будь-де — з комп'ютера, планшета чи телефона.

## Що всередині

| Модуль | Тема |
|--------|------|
| 1 | Фундамент — простори, проєкти, дошки |
| 2 | Backlog, задачі та спринти |
| 3 | JQL — мова запитів |
| 4 | Dashboards та звіти |
| 5 | Automation — рутина під контролем |
| 6 | Jira як PM — реальні сценарії |
| Фінальний проєкт | Побудова повноцінного середовища для команди |

Кожен модуль містить мету, теорію, практичні вправи і висновки.
